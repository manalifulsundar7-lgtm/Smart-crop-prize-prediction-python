#  Smart Crop Price Prediction

##  Overview

This project predicts crop prices using Machine Learning techniques. It helps farmers and traders make better decisions.

##  Aim

To forecast future crop prices based on historical data.

## Technologies Used

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib

##  How It Works

1. Data collection
2. Data preprocessing
3. Model training
4. Prediction

##  Run the Project

```bash
pip install -r requirements.txt
python main.py
```

## Output

* Predicted crop prices
* Graphical visualization
